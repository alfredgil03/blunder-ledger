# Opening lines

`a.tsv` to `e.tsv` are the opening list from [lichess-org/chess-openings](https://github.com/lichess-org/chess-openings), unmodified. They are released under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/) (public domain) by the Lichess contributors.

`review.py` uses them to tag known opening theory as "Book" and to name the opening on each game review.
